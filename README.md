# Product Marketing File

Fills in the product marketing file that the free Marketing Skills library reads before every job, using your real website, sales material and customer words.

**Who it is for:** Owners and marketing leads who want Claude's marketing advice built on their actual business.

**What you need:** Claude Code or Codex, your website address, any sales material you have, and a few real customer quotes, reviews or sales emails.

## Install

Open `SETUP-PROMPT.md`, copy the prompt in it, and paste it into a new Claude Code or Codex chat. It installs this skill and starts it. It keeps your existing skills as they are.
